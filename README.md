## About the Project

**Nexora HCM** is a modern, AI-assisted Human Capital Management platform developed for the **Saylani MERN Stack Final Hackathon 2026**.

Built using modern full-stack technologies, Nexora HCM aims to simplify and automate everyday HR operations through a centralized, secure, and user-friendly platform.

From employee management and attendance tracking to payroll processing and workforce analytics, the platform brings essential organizational operations together in one intelligent workspace.

Its integrated AI assistant takes the experience further by providing data-driven insights, answering HR-related questions, summarizing dashboard information, and simplifying leave applications through natural language.

Our vision is to transform traditional HR processes into a smarter, more efficient, and accessible digital experience.

## Security & Data Protection

Security is an important consideration in Nexora HCM.

- JWT-based authentication
- Role-based authorization
- Protected application routes
- Secure password hashing
- Organization-level data access
- Restricted access to sensitive HR information
- Validated API requests
